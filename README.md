## Installere

Kjør **Intervjueren-Setup.exe**. Ingen administratorrettigheter trengs, og alt programmet trenger følger med. Underveis velger du om det skal legges i Start-menyen, på skrivebordet og/eller starte med Windows.

> **«Windows beskyttet PC-en»?** Trykk *Mer informasjon* → *Kjør likevel*. Installasjonsprogrammet er bare ikke kodesignert.

## Bruk

| Handling | Tast |
|---|---|
| Vis / skjul overlegg | Alt+O |
| Start / stopp opptak | Alt+R |
| Pause / fortsett | Alt+P |
| Sett tidsmarkør | Alt+M |

- Velg **Video + lyd** (MP4) eller **Kun lyd** (MP3 / M4A / WAV).
- Tar opp både spill og talechat og mikrofonen din.
- Sett FiveM til **Windowed Borderless** for at overlegget skal vises over spillet.
- Tastene og alt annet endres under *Innstillinger* i overlegget.

## Krav

Windows 10 (2004 eller nyere) eller Windows 11, 64-bit. Et grafikkort eller en prosessor med maskinvarekoder (NVIDIA, AMD eller Intel) gir lettest opptak.
